1音色库 选择参考音频，写入当前副本下一次合成要用的音色。
2钢琴卷 看波形、音高曲线、尚未合成的窗口缺口。
3坐标格 宽 248 像素，永远四列：时间、音名、音分、频率。数字变化时格子宽度不变。
4合成参数 你正在拧的旋钮，下一次点「开始合成」才送进引擎。
5当前副本 这个 A/B 槽位里已经写好的合成结果，以及当时用过的全部参数。回放三种取值：合成音频、空（宿主原声）、原声（旁通）。旁通与清空作用在这个副本上。
6底栏动词 音高检测、开始合成、取消。取消只在任务进行中可点。
7过程格 宽 280 像素，永远占着底栏右侧。排队、加载、阶段进度、失败、未选音色，全部写在这一格。合成成功后这一格变回空白，耗时写到当前副本里。
