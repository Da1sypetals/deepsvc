# 数据模型的解释方法

本文规定解释数据模型时使用的方法与格式。

## 1. 中心

以走带上的一个音频事件为中心。音频事件是用户在时间线上拖动、切分、修剪的对象，
用户的每一个操作都作用在它身上，因此它是叙述的起点。

## 2. 术语表

先列术语表，一个概念只保留一个名字。含义相同的说法合并为一条。
每条术语一行，写明它是什么。

## 3. 对象树

用 mermaid `graph TD` 画一棵树，根是音频事件。

箭头方向表示持有与引用：`A --> B` 读作 A 持有 B 或 A 引用 B。
属于关系写成 `父 --> 子`。

每个节点写三样东西：名字、类型、示例取值。
类型用代码里的真实类型名，示例取值用一个具体场景的真实数值。
取值有范围的写出范围，取值有特殊含义的写出该含义，例如空容器表示未计算、
空指针表示未合成。

## 4. 字段说明

对象树之后逐字段说明，顺序与树中一致。
每条写明字段的类型、单位、坐标系、取值含义。

## 5. 取值走查

最后用一个具体的操作序列走一遍，每一步写出关键字段的前后取值，
用于验证模型自洽。

## 6. 禁止事项

不使用 ASCII 画图。
